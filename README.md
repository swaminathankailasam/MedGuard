MedGuard - Drug Interaction Severity Prediction
Tech:Python,Machine learning,XGBoost,RAndomForest,Flask,RDKit
An AI/ML-based healthcare system that predicts the severity of interactions between two drugs under a medical condition as Minor, Moderate, or Major, using molecular and clinical features. It uses models such as XGBoost and Random Forest and provides real-time predictions, confidence scores, and explanations through a Flask web interface.
